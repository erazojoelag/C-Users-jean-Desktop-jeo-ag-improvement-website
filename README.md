## Cómo usar
1. Abre la carpeta `/public/images` y agrega tus fotos como:
   - 1.jpg, 2.jpg, 3.jpg, ...
2. Sube este proyecto a Vercel:
   - https://vercel.com
   - Add New Project → Upload
3. (Opcional) Conecta tu dominio en Settings → Domains
